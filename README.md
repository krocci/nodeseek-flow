# NodeSeek Flow

NodeSeek 非官方 Chrome 扩展：让首页和评论连续阅读，保留浏览现场，并管理标签、屏蔽规则和跨设备配置。

当前版本 **0.1.18（预览版）**。本项目与 NodeSeek 官方无隶属关系。

## 功能

- 首页和帖子评论分别提前加载、缓存；同标签页返回或刷新时恢复阅读现场。
- 刷新按钮增量合并内容，用横幅区分更新；新评论/新帖子分别管理浏览状态。
- 用户资料先展示本机缓存，再后台更新；资料字段、顺序、字号和等级配色可调整。
- 标记按分组管理，屏蔽列表独立；支持选词快捷添加和用户页快捷操作。新关键词规则默认仅标题。
- 浅色、深色、跟随系统及暖色护眼配色；布局精简，适配不同窗口宽度。
- 热榜侧栏及浮动菜单入口，支持实时、日榜、周榜与展开榜单。
- WebDAV 同步规则、短语、共享设置，可选已读与阅读位置；并发修改显示冲突供选择。
- 可选自动签到：默认关闭、固定奖励，只在已登录且可见的论坛页面运行。

## 安装

1. 从 [Releases](https://github.com/krocci/nodeseek-flow/releases) 下载安装 ZIP，解压到一个长期保留的目录。
2. 在 Chrome 的扩展管理页打开开发者模式，选择“加载已解压的扩展程序”，选中含 manifest.json 的目录。
3. 暂停其他同时修改 NodeSeek 翻页、标签或主题的扩展/用户脚本，刷新论坛。
4. 点击扩展图标打开设置，也可使用论坛浮动导航中的 Flow 菜单。

更新时备份配置，解压新版覆盖同一加载目录，点击扩展管理页的重新加载，再刷新论坛及设置页。

从 0.1.14 或更早的本地版本升级时，0.1.15 起已更换扩展身份：先导出配置，再停用旧实例，单独加载新版并手动导入。新版不会自动读取旧扩展私有存储。自动签到开关及 WebDAV 凭据需要在新实例重新设置。

本项目的 manifest.key 为专门生成的公开身份公钥，用于固定开发加载 ID；不是密码或私钥，不代表 Chrome 商店签名。当前开发加载 ID 为 oblhhpiemeonmppdcdmbjakjfdiemlkk，设置页文件为 flow-settings.html。

## 缓存与刷新

默认缓存容量40 MB、保留7天，可在设置调整；每个浏览会话最多恢复/追加40页。首页与评论缓存独立，按账号、排序及会话区分。后台发现更新时不会直接重排正在阅读的列表。

缓存保存净化后的正文结构，不保存网站脚本、Cookie或CSRF令牌；图片仍按原地址加载。基础网页仍需能够打开，这不是完整离线镜像。浏览器重启后的标签页身份变化可能影响分页快照恢复。

动态页码可能随新帖移动；不能保证所有分页情况下完全无遗漏。403/429会暂停自动论坛请求至少30分钟。

## 自动签到

在设置页主动开启后执行，按UTC+8划分日期、使用固定奖励，账号隔离并防止多标签重复提交。0.1.18不再通过抓取首页HTML判断登录；使用当前页面账号和登录会话，提交后核对服务器的账号与当日记录。

失败状态显示具体阶段与原因。网站验证、限流或结果不明时冷却30分钟，不立即重复提交。关闭浏览器或没有前台论坛页面时不保证执行。开关和签到记录仅存本机，不随备份和WebDAV迁移。

## WebDAV

使用已经存在、私有且可写的HTTPS专用目录：填写连接信息并保存授权，先预览远端合并，再确认启用同步。AList账户已配置根目录时通常使用服务端对应的 /dav/ 路径；具体以自己的服务器配置为准。

挂载OneDrive且需要下载跳转的AList服务，可开启对应兼容选项并授权下载域名。默认拒绝跳转；兼容模式仅允许GET下载跳转。

同步文件为明文。只同步规则、短语、偏好及可选阅读记录，不上传正文、图片、资料缓存或WebDAV密码。密码仅保存在本机受信任的扩展存储。使用不可变的操作文件和版本向量合并；并发冲突需要手动选择，不以设备时钟决定覆盖关系。

浏览器关闭或后台被挂起会延迟同步。当前没有远端日志压缩；存在操作数、文件数及下载预算上限。

## 权限与数据

- storage：本机设置、规则、同步连接与运行状态。
- alarms：浏览器运行期间的周期任务。
- NodeSeek站点权限：页面增强及论坛接口请求。
- api.bimg.eu.org：获取热榜数据。该服务由第三方维护，可关闭热榜功能。
- 可选HTTPS主机权限：在配置WebDAV时按需申请相应服务主机。

没有额外的遥测或维护者数据收集服务。正常功能会访问NodeSeek、热榜服务及用户配置的WebDAV。导出配置可能包含自定义规则和阅读记录，请自行检查后再分享。

## 开发

需要Node.js 24及npm，依赖由锁文件固定：

~~~sh
npm ci
npm run check
npm test
npm run build
~~~

构建结果位于 dist，可直接加载。测试使用合成论坛页面与模拟存储，不需要登录或配置真实WebDAV。

~~~sh
npm run preview
~~~

本地预览为 http://127.0.0.1:4318/flow-settings.html；只使用示例数据，服务器重启后清空。先运行build生成预览所需文件。

## 验证范围与限制

- 0.1.18通过TypeScript检查及149项自动测试。
- 根据维护者实际使用确认，桌面浏览与规则管理、自动签到、Android Titanium及WebDAV双设备同步均可正常使用。
- 评论操作依赖站点已有组件；站点改版可能需要适配。不支持旧Helper的全部功能，例如趋势图、图床上传和抽奖管理。
